An attacker finds an unpatched application, and tests it for react to shell vulnerability. Now the attack begins. The attacker tries to get the user id, and finds tha application runs as root. The run time details reveal Debian and help the attacker understand the environment. Code execution gives the attacker a foothold. Next, the attacker inspects the container. Environment variables reveal Kubernetes and a secret available to the app. The attacker reads the container secret directly from the process environment. A mounted service account token exposes the pod's Kubernetes identity. The attacker uses the token to authenticate a request to the Kubernetes API. The compromised app exposes a secret and a workload identity. Next comes cluster access. The attacker discovers an internal API listening on port 3000 in another namespace. A request from the compromised pod returns two internal user records: Alice and Bob. The Kubernetes API reveals a secret in the internal namespace. Broad R B A C permissions let the attacker retrieve the secret and decode its value. Internal data and the cluster secret are exposed. The attacker now investigates the cloud layer identity. A W S environment variables identify the IAM role and the separate IRSA token file. IRSA exchanges the projected token for temporary AWS credentials. The role's permissions determine access. The attacker uploads a Node.js script to use the pod's AWS identity. Using the pod's AWS role, the attacker lists secrets and finds a RDS credential. Secrets Manager returns the RDS credential, including its username, password, and port. The script retrieves the cloud secret, completing access to all three secrets. The app vulnerability enables remote code execution. Readable environment variables exposes container secret. A mounted token makes the API server and the cluster secret accessible due to broad RBAC. The flat network in cluster exposes internal data. IRSA injected token and assume role expose the IAM role credentials. And broad IAM permissions allow secret. The attacker has reached the secrets.
